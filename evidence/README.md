# Evidence

Generated by `npm run evidence` (real model-driven discovery, needs `OPENAI_API_KEY`) or
`npm run demo:offline` (identical pipeline, scripted decider, no key). Runs 1 and 2 are the
LLM-driven discovery runs; everything from 3 on is the deterministic engine with no model involved.

Each run directory contains:

| File | What |
|---|---|
| `run.jsonl` | structured event log: every observation, decision, policy verdict, action, condition, recovery, drift warning and intervention |
| `result.json` | the result contract the caller receives |
| `shots/` | a screenshot per step |
| `snapshots/` | on failure, the serialized DOM of every frame |
| `observations/` | discovery only: the exact text the model saw each step |
| `system-prompt.txt` | discovery only |
| `capability.json` | discovery only: the artifact that run produced |
